# Project Overview
Awesome Startup is a fictional company with remote employees located around the world. This project is an interactive employee directory designed to make it easy for employees to find and access one another's contact information.

Using the Random User Generator API, I built an application that dynamically retrieves and displays 12 employee profiles in a responsive grid layout.

Each employee card displays their profile picture, name, email address, and location. Users can click on an employee's card to open a modal window containing additional information, including their phone number, birthday, and address.

## Technologies Used
- HTML5 – Page structure and content
- CSS3 – Styling and responsive grid layout
- JavaScript (ES6+) – DOM manipulation, event handling, and dynamic content
- Fetch API – Asynchronous HTTP requests and JSON data handling
- Random User Generator API – External API providing employee profile data

## What I Learned
This project strengthened my understanding of working with public APIs and asynchronous JavaScript. I gained hands-on experience with:
- Making HTTP requests using the Fetch API
- Working with asynchronous operations using async/await
- Parsing JSON responses and extracting relevant data
- Dynamically generating HTML elements using JavaScript
- Implementing interactive modal windows using DOM manipulation and event listeners
