I built an app for a fictional company called Awesome Startup, a distributed company with remote employees working all over the world. 
They need a smart way for employees to share contact information with each other.
I used the Random User Generator API (https://randomuser.me/) to grab information for 12 random “employees,” and used that data to build 
a prototype for an Awesome Startup employee directory.

Through this project, I learned how to request JSON objects from the API and parse through the data so that 12 employees are listed in a grid 
with their thumbnail image, full name, email, and location. Clicking on each employee's image or name will open a modal window with more detailed 
information,such as the employee's birthday and address.

This project demonstrates my ability to work with public APIs, making API requests, and asynchronously handling data returned from requests 
and displayed in an app.
